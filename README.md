# Algorithm-intelligent-dashboard

This project aims to help students easily understand and compare different algorithms based on performance metrics like execution time and memory usage.

Microsoft PowerBI
Kaggle Dataset

1)Collected dataset from Kaggle.
2)Performed data understanding and preprocessing using RapidMiner operators.
3)Applied Decision Tree operators to analyze algorithm performance.
4)Identified the best algorithm based on execution time and memory usage.
5)Exported processed data and built an interactive Power BI dashboard.
6)Designed visualizations including cards, comparison graphs, and UI elements highlighting the best and avoidable algorithms.
